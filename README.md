# LeadHunter — поиск клиентов, которым нужен сайт

Парсит **2ГИС**, **Яндекс Карты** и **Google Maps** и находит конторы:

- **без сайта** вообще;
- **только соцсети / онлайн-запись** — вместо сайта VK, Instagram, Telegram, Taplink, YClients, Dikidi, Avito и т.п.;
- **сайт на конструкторе** — Tilda, Wix, uKit, Nethouse, Flexbe, Craftum, Taplink, Битрикс24.Сайты, uCoz и др. (определяет по домену и по коду страницы);
- **сайт не работает** — домен не существует, ошибка сервера, заглушка «домен продаётся»;
- **слабый сайт** — нет адаптива под телефон, нет HTTPS, копирайт старше 4 лет, древняя вёрстка.

У каждой конторы считается «потребность в сайте» (0–100 %). Вкладка «Горячие» показывает всех, кому нужен сайт.

## Запуск

Нужен Node.js 18+ и установленный Microsoft Edge или Google Chrome (парсер управляет обычным браузером).

```bash
npm install
```

```bash
npm start
```

Открой http://localhost:3777 (или просто запусти `start.bat` двойным кликом).

## Telegram-бот

Бот запускается вместе с программой (`npm start` / `start.bat`). Он работает в том же процессе, что и веб-интерфейс, поэтому база и парсер у них общие. Парсинг можно запустить с ПК или из Telegram, прогресс виден в обоих местах. Статусы, которые ты меняешь в боте, сразу появляются на ПК.

1. Токен бота лежит в `.env` в строке `TELEGRAM_BOT_TOKEN=...`.
2. Запусти программу и напиши боту `/start`. Первый, кто это сделает, станет владельцем (ID сохраняется в `data/telegram.json`), остальным доступ закрыт. Чтобы пустить ещё кого-то, впиши его ID через запятую в `TELEGRAM_ALLOWED` в `.env`.
3. Кнопки: 🚀 Парсинг (мастер), 📊 Статус, 🔥 Горячие (карточки со сменой статуса и текстом для первого касания), 📁 Экспорт CSV, 🔄 Проверить сайты, ⏹ Стоп.

Бот работает, только пока программа запущена на ПК: сам браузер-парсер живёт на компьютере.

### Мини-приложение в Telegram

Кнопка **LeadHunter** слева от поля ввода в чате с ботом (или `/app`). Внутри: парсер с живым прогрессом, база с фильтрами и поиском, карточка конторы (позвонить, WhatsApp, статус, заметка, текст первого касания), воронка клиентов, статистика и настройки.

- Telegram открывает мини-приложения только по HTTPS, поэтому программа сама поднимает бесплатный туннель Cloudflare через `cloudflared`. Его адрес меняется при каждом запуске, а кнопка в боте обновляется автоматически.
- Через туннель открывается только `/tg/`. API отвечает лишь на запросы с подписью Telegram от владельца бота, а остальным возвращает 401.
- На ПК мини-приложение можно открыть по адресу http://localhost:3777/tg/.
- Свой постоянный адрес можно задать в `.env` через `MINIAPP_URL=https://...`, а туннель отключить через `TUNNEL=off`.

## Как пользоваться

1. **Парсер**: впиши ниши (или нажми на готовые) и города, выбери источники и лимит → «Запустить парсинг».
2. Найденные конторы сразу появляются в **Базе**, сайты проверяются автоматически.
3. Нажми на карточку: контакты, причины, ссылки для поиска владельца (Google, Яндекс, Rusprofile, VK), заметки и готовое сообщение для первого касания (копируется или открывается в WhatsApp).
4. «+ В базу» → контора попадает в **Клиенты** (воронка с перетаскиванием: В базе → В работе → Клиент → Отказ).
5. «Экспорт CSV» — выгрузка для Excel / Google Таблиц.

## Важно

- **Выключи VPN.** 2ГИС, Яндекс Карты и большинство сайтов в .ru не открываются из-за рубежа. Если парсер это заметит, он предупредит в логе, а такие сайты пометит «Не проверен», а не «Не работает». Без VPN нажми «Проверить сайты».
- При первом запуске **не включай фоновый режим**: если Яндекс или 2ГИС покажут проверку «я не робот», пройди её в окне браузера — парсер дождётся и продолжит. Куки сохраняются в `data/browser-profile`, дальше капча будет реже.
- Если капча часто появляется, увеличь паузу в **Настройках**.
- Данные лежат в `data/leads.json`, настройки в `data/settings.json`.

## Устройство

```
server.js              HTTP-сервер + API + SSE (живой прогресс)
src/jobs.js            очередь: ниши × города × источники, проверка сайтов
src/sources/google.js  Google Maps: лента результатов + карточка каждой организации
src/sources/twogis.js  2ГИС: перехват JSON-ответов catalog.api.2gis
src/sources/yandex.js  Яндекс Карты: перехват /maps/api/search + state-view
src/siteCheck.js       классификация сайта (конструкторы, соцсети, заглушки, слабые сайты)
src/db.js              хранилище JSON, склейка дублей между источниками
public/                интерфейс
```
